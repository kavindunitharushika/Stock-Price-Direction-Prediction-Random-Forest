# Stock Price Direction Prediction Using Random Forest Classification

## Project Overview

This group research project focuses on predicting the next-day stock price direction (UP or DOWN) of John Keells Holdings PLC (JKH), listed on the Colombo Stock Exchange (CSE), using a Random Forest Classification model.

The study explores how historical stock market data and technical indicators can be used for stock price direction prediction.

## Research Objectives

- Predict next-day stock price direction using Random Forest Classification.
- Analyze historical stock prices and trading volume.
- Apply technical indicators for feature engineering.
- Evaluate the predictive performance of the model.

## Methodology

**Dataset:** Historical JKH stock market data from January 4, 2010, to January 9, 2026.

**Programming Language:** Python

**Machine Learning Algorithm:** Random Forest Classifier

**Technical Indicators:** Including RSI, MACD, OBV, and Rate of Change (ROC).

**Model Configuration:**
- Number of trees: 100
- Maximum tree depth: 15
- Classification: UP / DOWN

## Research Results

| Evaluation Metric | Result |
|---|---|
| Training Accuracy | 93.03% |
| Testing Accuracy | 54.77% |

The results demonstrate the challenges of predicting stock price movements using historical market data. Although the model achieved high training accuracy, its performance on unseen test data was considerably lower.
